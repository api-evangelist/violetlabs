## Integrations (Apps)

Violet connects the hardware engineering software stack — PLM/PDM, ERP,
CAD/CAE, MES, requirements, procurement, and collaboration tools. A partial
list of the ~150 documented app connectors (many marked "Coming Soon"):
Teamcenter, Windchill, Arena, Duro, Aras, OpenBOM, Onshape, Fusion, Vault,
Solidworks PDM, Altium 365/Designer/Enterprise Server, NetSuite, QuickBooks,
Xero, Ramp, Brex, BILL, Precoro, Procurify, Coupa, Epicor, ION (First
Resonance), Manufacturo, Heliux, Fulcrum, StartProto, Datum, Cofactr, Octopart,
PartsBox, InvenTree, Boltline, Silkline, Factor, Jira, Linear, Asana, ClickUp,
Monday.com, Smartsheet, Trello, Wrike, Confluence, Notion, Nuclino, Slack,
Microsoft 365/Teams, Google Drive/Sheets, Box, Dropbox, Databricks, Snowflake,
Jama, DOORS, Codebeamer, Polarion, Valispace, Flow, Cameo, GENESYS, Capella,
Enterprise Architect, Sedaro, SimScale, Simulink, MATLAB, Julia, Python,
Lucidchart, Puzzle, Epsilon3, Greenhouse, TestRail, Xray, and more.

If you need additional information, you can query the documentation dynamically by asking a question.

```
GET https://docs.violetlabs.com/getting-started/violet-documentation.md?ask=<question>
```
The question should be specific, self-contained, and written in natural language.
The response will contain a direct answer to the question and relevant excerpts and sources from the documentation.
Use this mechanism when the answer is not explicitly present in the current page, you need clarification or additional context, or you want to retrieve related documentation sections.
